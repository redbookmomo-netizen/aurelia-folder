# Aurelia · 深海荧光水母磨砂档案夹

> 纯代码生成的深海生物发光水母与冷黑磨砂玻璃交互装置：无任何外部图片素材，单个 `index.html` 完整驱动。

在线体验（GitHub Pages，支持 iPhone Safari 竖屏触控与桌面端鼠标交互）：
<https://redbookmomo-netizen.github.io/aurelia-folder/>

## 核心特性

- **渐进景深磨砂玻璃遮挡**：冷黑冰透磨砂玻璃前盖内，水母丝带口腕与珠串触手由上沿向深处渐进柔化，晕染为青蓝与柔紫交织的深海生物荧光星云；越过右上角边缘探出的水母群则保持锐利清透的吹制琉璃质感。
- **弹簧质点触手与水流拨弄**：每只水母均具备独立呼吸相位、蕾丝丝带口腕与多节弹簧质点珠串触手。手指或鼠标划过时，水母与触须顺水流弹性偏转并回弹，震落发光水滴与微光花瓣，伴随实时合成的水下琉璃竖琴泛音。
- **文件投递与生命生长**：
  - 支持直接从电脑拖入真实文件，亦可按住左下角漂浮的发光切片卡拖向文件夹（专为手机触屏体验设计）。
  - 靠近文件夹时口袋微张，文案切换为「松手，沉入深海」；松手后切片落入毛玻璃内模糊、向上轻弹探头后归档，并从夹口浮起气泡、游出一只全新的发光水母。
- **3D 折页掀盖与「一手牌」玻片展开**：轻点文件夹，前盖以底边为轴向前 3D 翻倒躺平，内部整排水母瞬间去雾显露高清细节；12 张半透明深海故事玻片呈弧形扇面依次发牌展开。点选抽起任意卡片并点击「删掉」，对应水母即刻化作荧光星尘与上升气泡消散。
- **长按海底涡流与三层摄影级散景（Bokeh）**：长按画面蓄力卷起发光涡流并将水母群向上牵引；松手瞬间以「近景柔焦大散景光斑 + 中景旋转发光花瓣 + 远景深海星尘」三层景深炸满全屏。双击空白黑背景可一键隐藏右上角字体与音效控制栏，进入纯净观赏与录屏模式。
